# 英語学習マトリクス診断

外的必要性と学習意欲の2軸から、英語学習の現在地と次に取るべき方針を診断する静的Webサイトです。

## 公開ファイル

- `index.html`
  - GitHub Pagesでそのまま公開できる単一HTMLです。
  - PCのクリック、スマートフォンのタップ、ドラッグ、キーボード操作に対応しています。
  - 診断結果URLを `X`、`LINE`、`Threads`、URLコピーで共有できます。

## 診断タイプ

- 目的達成型学習者: 必要性も意欲も高い
- 義務対応型学習者: 必要だが、勉強したくない
- 好奇心型学習者: 不要だが、勉強したい
- 保留・低優先タイプ: 不要で、勉強したくない
- 検討中タイプ: 中央付近

## GitHub Pagesでの公開手順

1. このフォルダをGitHubリポジトリにpushします。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
4. `Branch` を `main`、フォルダを `/root` にして保存します。
5. 表示されたURLで `index.html` が開くことを確認します。

## ローカル確認

`index.html` をブラウザで直接開くだけで動作します。ローカルサーバーは不要です。

## 既存ファイルについて

この作業前からあるラブクラフト診断関連のHTMLは削除していません。今回の公開入口はルートの `index.html` です。
